Portail de Dématérialisation & Gestion des Congés

Projet Professionnel Validé

S Situation & Problème

Les demandes de congés dépendaient d'un circuit papier source de retards administratifs et de risques d'erreurs de décompte manuel.

T Tâche Assignée

Concevoir et déployer une application interne permettant de soumettre des demandes, de calculer automatiquement les absences, d'apposer une signature sur canvas et d'exporter des PDF réglementaires.

A Actions Réalisées

  • Maquettage UI/UX sous Visily conforme à la charte.
  • Développement Front-End sous Next.js, React et Tailwind CSS.
  • Intégration d'un module de signature tactile sur canvas et export dynamique via jsPDF.
  • Déploiement sur VM Debian (Proxmox), configuration Nginx et PM2.
  • Support technique : sécurisation de postes, VPN et KeePass.

R Résultats & Impact

Suppression complète du support papier, fiabilité absolue des calculs légaux et réduction drastique du temps de validation des congés.

Veille Technologique : Test-Driven Development (TDD)

Élever la qualité logicielle et réduire la dette technique par les tests unitaires.

Le Cycle Fondamental : Red - Green - Refactor

1. RED

Écrire un test qui échoue

Formalisation précise du besoin métier en amont de toute écriture de code.

2. GREEN

Code minimaliste

Écriture du code strict nécessaire pour valider le test au vert.

3. REFACTOR

Factoriser & Nettoyer

Optimisation de l'architecture logicielle en conservant la couverture de tests.

Synergie avec l'IA Générative :

Le TDD sert de garde-fou impératif face aux assistants de code : le développeur spécifie par le test, l'IA génère la solution minimale validée.

Outillage Moderne :

Utilisation d'environnements rapides comme Vitest/Jest (React), PyTest (Python) ou PHPUnit.
